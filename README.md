# boki-app-prompt

あなたは簿記教育の教材作成者です。
Webアプリの入力欄に貼り付けて使用するための、新しいストーリー仕立ての簿記仕訳問題データ（JSON形式）を作成してください。

【希望の世界観・テーマ】
（例：サイバーパンク・ハッカー / 終末世界のサバイバル商人 / 魔法学園の購買部 / アイドル事務所の立ち上げ / 税務調査官の追跡劇）
※ここに作成したい世界観やテーマを記入してください。

【作成条件】
1. 問題数：5問（1問目から5問目にかけて、設定したテーマに沿って状況が展開する連続ストーリーにすること）
2. 難易度：日商簿記3級〜2級基礎レベル
3. 複合仕訳（借方または貸方に2つ以上の科目が並ぶ仕訳）を1〜2問含めること。
4. 物語文の末尾には、使用する勘定科目のヒントを括弧書きで記載すること（例: （仕入）（現金））。
5. 各問題の借方合計金額と貸方合計金額は必ず一致させること。

【厳格な構文ルール（エラー防止）】
Webアプリの JSON.parse() でそのまま読み込むため、以下のルールを厳密に守ってください。
・出力は全体を [ で開始し、] で終了する単一のJSON配列のみを出力すること。
・前置きの挨拶、解説、Markdownのコードブロック記号も含め、JSON配列以外の文字列は一切出力しないこと。
・プロパティ名および文字列は必ず半角ダブルクォーテーション " で囲むこと（全角引用符やシングルクォーテーションは使用禁止）。
・金額（amount）にはカンマを使用せず、半角数字のみで記述すること（例: 100000）。
・配列やオブジェクトの末尾要素の後に余計なカンマを付けないこと。

【出力フォーマット】
[
  {
    "story": "世界観に沿った問題文。（勘定科目1）（勘定科目2）",
    "debit": [
      { "account": "借方勘定科目", "amount": 100000 }
    ],
    "credit": [
      { "account": "貸方勘定科目", "amount": 100000 }
    ],
    "explanation": "なぜその勘定科目になるのかを初心者向けに解説した文章。"
  }
]
